# Second Opinion

Premium medical imaging second-opinion frontend prototype built with Next.js, TypeScript, Tailwind CSS, and Lucide icons.

## Scope

This repository contains the UI foundation for:

- long-form public homepage
- how-it-works, doctors, doctor profile, specialties, blog, support, and legal placeholder pages
- login and registration screens
- patient dashboard
- multi-step new case wizard
- DICOM upload UI
- case detail, images, and result screens

The prototype uses mock data only. It does not include backend services, production authentication, payments, real DICOM ingestion, health data storage, or production APIs.

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm run lint
npm run build
```
